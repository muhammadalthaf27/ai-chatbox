# 🤖 AI Chatbot Assistant — Muhammad Althaf S

A conversational AI chatbot powered by **Google Gemini API**, built with Python Flask.

## 🚀 Quick Setup (5 minutes)

### 1. Get Free Gemini API Key
- Go to: https://aistudio.google.com/app/apikey
- Sign in with Google → Create API Key → Copy it

### 2. Install dependencies
```bash
pip install flask google-generativeai
```

### 3. Add your API key
Open `app.py` and replace:
```python
GEMINI_API_KEY = "YOUR_GEMINI_API_KEY"
```

### 4. Run the app
```bash
python app.py
```

### 5. Open in browser
```
http://localhost:5000
```

## 🛠️ Tech Stack
- **Backend**: Python, Flask
- **AI**: Google Gemini 1.5 Flash API
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Features**: Real-time chat, conversation history, markdown rendering, typing indicator
